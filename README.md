Para este laboratorio se programó un juego de tipo "Simón dice" donde el usuario escoge uno de dos niveles usando los botones laterales.
Luego, el usuario debe mirar detenidamente la secuencia mostrada en la matriz de LEDs y repetirla con los 4 botones disponibles.
Si se equivoca en algún punto, se ejectua la secuencia de fallo y se reinicia el juego.
Si completa el nivel exitosamente, se ejecuta la secuencia de éxito y se reinicia el juego.
